What is OpenCode?

OpenCode is an open source AI coding agent that runs in your terminal, desktop, or IDE. It gives you the same agentic coding workflow as commercial tools — editing files, running commands, exploring codebases — while staying fully open and self-hostable. With free AI models included and support for 75+ providers, it's a privacy-respecting Claude Code alternative built by the community.

The project is published under the MIT license and lives at github.com/anomalyco/opencode. It's written in TypeScript and works on macOS, Windows, and Linux.

Frequently asked questions

Is OpenCode really free and open source?

Yes. OpenCode is released under the MIT license and the source is public on GitHub. The agent itself is free to use; you only pay your model provider if you use a paid model (free models are included).

How is OpenCode a Claude Code alternative?

OpenCode offers the same agentic coding workflow — file edits, command execution, and codebase exploration — but it's open source, runs locally, and connects to any of 75+ model providers instead of being tied to a single vendor.

Which models and providers are supported?

OpenCode supports 75+ providers through Models.dev, including Anthropic Claude, OpenAI GPT, Google Gemini, and local models via Ollama. You can also log in with GitHub Copilot or ChatGPT Plus/Pro.

Does OpenCode store or send my code anywhere?

No. OpenCode does not store your code. Prompts and repository content are only sent to the model provider you configure, and you remain in control of what leaves your machine.
